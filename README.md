## GitHub Pages 배포 설정 방법
1. 이 레포지토리의 **Settings** (설정) 탭으로 이동합니다.
2. 왼쪽 메뉴에서 **Pages**를 클릭합니다.
3. **Build and deployment > Branch** 항목에서:
   - Branch: `main` (또는 `master`) 선택
   - Folder: `/ (root)` 선택
4. **Save**를 누르면 잠시 후 나만의 게임 주소가 생성됩니다!
   - 예: `https://<사용자아이디>.github.io/<저장소이름>/`
